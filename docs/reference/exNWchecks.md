# Sample NestWatch Checks Dataframe for Examples

A random set of 10 nesting attempts from the NewstWatch database to use
in running R documentation examples.

## Usage

``` r
exNWchecks
```

## Format

A dataframe with 79 observations of 21 variables. See
\<https://doi.org/10.1002/ecy.4230\> for details of variables.
