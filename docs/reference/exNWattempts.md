# Sample NestWatch Attempts Dataframe for Examples

A random set of 10 nesting attempts from the NewstWatch database to use
used in running R documentation examples.

## Usage

``` r
exNWattempts
```

## Format

A dataframe with 10 observations of 32 variables. See
\<https://doi.org/10.1002/ecy.4230\> for details of variables.
